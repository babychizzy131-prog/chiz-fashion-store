# Chiz Fashion Store 🛍️

A responsive fashion e-commerce website built with HTML, CSS, and JavaScript.

## 🌐 Live Website

https://babychizzy131-prog.github.io/chiz-fashion-store/

## ✨ Features

- Responsive fashion store design
- Product search
- Product categories
- Shopping cart
- Add to cart functionality
- Quantity controls
- Remove items from cart
- Automatic cart total
- Wishlist functionality
- Product images
- Interactive navigation
- JavaScript-powered functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 📌 Project Purpose

This project was created to practice and demonstrate my frontend web development skills by building a functional fashion e-commerce website from scratch.
